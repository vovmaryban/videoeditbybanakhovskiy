# Video Studio — контекст для Claude

Власна локальна студія монтажу вертикальних відео користувача (Володимир, маркетолог, Instagram/TikTok). Мета — рівень платформ «вибираєш стиль і одразу бачиш»: субтитри, стилістика, анімації, ефекти, колір, музика з живим переглядом, далі експорт MP4. Спілкування й інтерфейс — українською.

Користувач працює на **Windows**, запускає студію через `setup.bat` / `start.bat` / `update.bat`. Він не програміст: пояснюй простими словами, команди давай готовими до вставки.

ПК користувача: ноутбук Intel i5-13420H (8 ядер / 12 потоків), 24 ГБ RAM, лише вбудована Intel UHD (NVIDIA немає → whisper тільки на процесорі). Node 24 LTS працює (README радить 22 — обидва ок). Студія склонована в `C:\Users\1\Desktop\video-studio\videoeditbybanakhovskiy`, референси — `C:\Users\1\Desktop\video-studio\Монтаж\Реверенси`.

## Архітектура

- `src/remotion/` — композиція Remotion (`Reel.tsx`), спільна для живого перегляду (`@remotion/player` у браузері) і рендеру (`@remotion/renderer`). Що бачиш = що рендериться.
  - `types.ts` — модель даних (Project, Clip, Word, ProjectStyle = captions + color + camera + **fx** + **headline** + music).
  - `timeline.ts` — увімкнені фрази → вихідна шкала; слова → сторінки субтитрів.
  - `Captions.tsx` — субтитри: 10 анімацій появи × 11 режимів слів (у т.ч. blur-in, typewriter, rise), ключові слова (★ або автовибір найдовшого/останнього) як колір / інший шрифт / великим / бокс / маркер / світіння, «два яруси», вирівнювання, нахил, фони: плашка, по рядках, теги на кожне слово, скло, мазок пензля.
  - `Headline.tsx` — заголовок поверх відео (10 виглядів із референсів). `y` — **верхній** край (за замовчуванням 0.215 = одразу під сліпою зоною).
  - `color.ts` — **кольорокорекція окремо від стилю**: фільтр (14 шт.) × сила + 11 повзунків як у CapCut. Рендериться справжніми тоновими кривими SVG-фільтром (`feComponentTransfer` + `saturate`) по пікселях відео, потім віньєтка/зерно. `normalizeColor` мігрує старий формат (`preset`, `brightness: 1.02`…).
  - `presets.ts` — пресети субтитрів (28 з референсів + 18 класичних), камери, переходів, кадрів, стилі монтажу `LOOKS` (25). **Стиль монтажу ніколи не змінює колір** (`applyLook`). `normalizeStyle` доповнює старі проєкти новими полями.
  - `fonts.ts` — 33 вбудовані шрифти (`public/fonts`, усі з кирилицею, перевірено по METADATA Google Fonts) + свої шрифти користувача (`data/fonts`). `useFonts` вантажить кілька сімейств (субтитри, акцент, заголовок).
- `src/ui/` — `Home.tsx`, `Editor.tsx` (вкладки: Стилі, Субтитри, Ефекти, Колір, Камера, Музика, Текст і склейки, Експорт), `VariantGrid.tsx` (живі мініатюри; плеєр монтується лише коли плитка на екрані), `controls.tsx`.
- `server/` — Express на порту 4610.
  - `projects.ts` — обробка: проксі 1080×1920 + 540×960, аудіо 16 кГц, паузи, розпізнавання (режими fast/precise), фрази з вимкненими дублями. Пише в лог і в `project.asrSeconds` час розпізнавання.
  - `cuts.ts` — мовлення відносно шуму кімнати, фрази, вікна, `packWindows` / `snapWords` / `suspiciousRuns` (двопрохідний режим), автовизначення дублів.
  - `whisper.ts` — whisper.cpp v1.8.2; на Windows **OpenBLAS-збірка** (`tools/whisper-blas`), стара `tools/whisper` лишається запасною.
  - `render.ts` — bundle + renderMedia, версії v1, v2… ніколи не перезаписуються.
- `scripts/preview-looks.ts` — рендерить по кадру на кожен стиль через справжній рендерер у `tools/looks/` (перевірка без браузера).
- `docs/references.md` — розбір усіх 108 референсів на прийоми + що з них уже в студії і що ні.
- ffmpeg/ffprobe — з пакета компоситора Remotion (немає fps/setsar тощо). Для аналізу референсів на ПК стоїть повний ffmpeg (winget Gyan.FFmpeg), студія від нього не залежить.
- Дані користувача: `data/projects/<id>/`. `data/` і `tools/` у .gitignore і **виключені зі стеження Vite** (інакше Vite падає з EBUSY, коли туди пишуться файли).

## Рішення, які вже перевірені (не повторювати помилок)

- whisper зливає кілька дублів в одному вікні в один текст і **розтягує окремі слова на 2–3 с**. Саме це — ознака злитого дубля.
- Скорочений аудіоконтекст (`-ac`) + `--dtw` пришвидшує, але псує текст і час слів. Не вмикати.
- **Заміри на ПК користувача** (68 с тестового запису з навмисним дублем, мова uk):
  - старий режим «кожна фраза окремо», звичайна збірка: **618 с** (15 вікон; енкодер ~20 с на вікно незалежно від довжини фрази);
  - OpenBLAS-збірка: енкодер 16 с замість 20,5 с на вікно, текст ідентичний;
  - **двопрохідний «швидко»** (3 вікна по ≤28 с + повторно лише 4 сумнівні фрази): **150 с**, дубль вимкнено правильно, текст навіть кращий (більше контексту).
  - Правило сумнівної фрази: слово довше 2 с, або щільність < 0.45 × медіани цього ж ролику, або порожня фраза ≥ 0.8 с; + сусіди (пауза < 1.5 с, фраза < 10 с). Абсолютний поріг «< 0.9 слова/с» НЕ працює: повільний мовець на вулиці дає 14 з 18 фраз.
  - `snapWords`: слово, що впало в паузу, займає голову сусіднього слова, а не край фрази (інакше ламався порядок слів).
- Remotion рендер перевірено: 1080×1920 H.264, гучність близько −13,5 LUFS; усі 25 стилів монтажу перевірено рендером кадрів (`scripts/preview-looks.ts`).

## Правила для монтажу (від користувача)

- Сліпі зони Reels 1080×1920: верх 400 px, низ 450 px, праворуч 159 px (від y=1000 вниз). Текст туди не ставити. У перегляді показуються червоним. Пресети й заголовок налаштовано так, щоб не залазити.
- Склейки тільки в паузах між фразами, ніколи всередині слова.
- Звукові ефекти — лише справжні записи (семпли), не синтезовані кодом.
- Графіка «солідна», не мультяшна (жодних кольорових емодзі-стікерів).
- Не прив'язуватись до старого стилю користувача (чорна плашка + Unbounded): широкий вибір стилів, у т.ч. з референсів.
- **Стилі монтажу не залежать від кольорокорекції**: колір — окремий шар (фільтр + сила + повзунки), стиль його не чіпає.
- Раніше здані відео не перерендерювати без запиту.

## Наступна сесія

1. Попросити користувача запустити `update.bat` → `start.bat`, завантажити свій справжній сирий запис і подивитися стилі; зібрати відгук.
2. Етап 3: вирізання людини → «текст позаду голови» (найчастіший «вау»-прийом у референсах), потім картки-вставки і звуки.
