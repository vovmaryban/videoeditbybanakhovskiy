# Video Studio

Локальна студія монтажу вертикальних відео (Reels / TikTok / Shorts) з живим переглядом.
Завантажуєш сирий запис → студія сама вирізає паузи й невдалі дублі, розпізнає текст → ти перемикаєш стилі субтитрів, колір, рух камери, музику і **одразу бачиш результат** → експорт MP4 1080×1920.

Усе працює на твоєму комп'ютері: відео нікуди не вивантажуються.

## Встановлення на Windows (один раз)

1. Встанови **Node.js 22 LTS**: https://nodejs.org (кнопка LTS, далі «Next» до кінця).
2. Встанови **Git**: https://git-scm.com/download/win (усе за замовчуванням).
3. Відкрий папку, де хочеш тримати студію (наприклад `Документи`), клікни в адресний рядок провідника, напиши `cmd` і натисни Enter. У чорному вікні встав:
   ```
   git clone https://github.com/vovmaryban/videoeditbybanakhovskiy.git video-studio
   ```
   Git попросить увійти в GitHub — увійди своїм акаунтом.
4. Відкрий папку `video-studio` і двічі клікни **`setup.bat`**. Він встановить бібліотеки і розпізнавання мови (≈ 600 МБ, 5–15 хв залежно від інтернету).

## Щоденна робота

- Двічі клікни **`start.bat`** → студія відкриється в браузері на `http://localhost:4610`.
- Не закривай чорне вікно, поки працюєш.
- Перший експорт сам докачає рушій рендеру (~100 МБ), далі — швидко.

## Оновлення

Коли Claude допише нові можливості — двічі клікни **`update.bat`**. Твої проєкти (папка `data`) не чіпаються.

## Що є зараз (етап 1)

| Вкладка | Що робить |
|---|---|
| **Стилі** | готові «образи»: субтитри + колір + камера одним кліком |
| **Субтитри** | 18 стилів сіткою з живими мініатюрами (наведи — програє), 20 шрифтів з українськими літерами + свої шрифти, товщина, розмір, кольори, плашки, контур, тінь, світіння, 6 анімацій появи, 8 режимів слів (караоке, плашка, маркер, стрибок…), позицію тягнеш мишкою |
| **Колір** | 9 кольорових пресетів + яскравість, контраст, насиченість, тепло/холод, підняті тіні, віньєтка, плівкове зерно |
| **Камера** | статика, зміна крупності на склейках, повільний наїзд, різкий удар |
| **Музика** | свій трек, гучність, автоприглушення під голос, плавний кінець |
| **Текст і склейки** | кожна фраза з галочкою (дублі й шум вимкнені автоматично), виправлення слів, ★ акцентні слова, повторне розпізнавання |
| **Експорт** | MP4 1080×1920 H.264; кожна версія — новий файл v1, v2…, старі не перезаписуються |

Червоні зони на перегляді — сліпі зони Reels (верх 400 px, низ 450 px, праворуч 159 px); вмикаються галочкою «сліпі зони».

## Далі

2. Анімації й переходи, наїзди на ключові слова, заголовки й плашки.
3. Ефекти: текст і картинки позаду людини (вирізання), вставки, картки, звукові ефекти.
4. Бібліотека стилів з твоїх референсів: скидаєш ролики → Claude розкладає їх на прийоми → новий стиль у студії.
5. Кнопка «Автомонтаж».

## Якщо щось не так

- Скопіюй текст з чорного вікна і надішли Claude.
- Проєкти лежать у `data/projects`, кожен у своїй папці (оригінал, проксі, `project.json`, `exports`).

## Для розробки

```
npm install
npm run setup:whisper
npm run dev        # інтерфейс з гарячим перезавантаженням: http://localhost:5173
```

Стек: React + Vite (інтерфейс), [Remotion](https://www.remotion.dev) (однаковий код для живого перегляду і рендеру), Express (локальний сервер), whisper.cpp (розпізнавання). Remotion безкоштовний для приватних осіб і компаній до 3 працівників.
